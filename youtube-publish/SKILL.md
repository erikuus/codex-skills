# YouTube Publish

1. Identify the video file and target channel from the request and recent work. Open YouTube Studio in the requested browser session and verify the active channel before uploading.
2. Open the upload dialog and select the exact file with the browser tool's file chooser. If Studio presents agreement to its terms as part of uploading, follow the browser tool's action-time confirmation rule. If the upload result is unclear, check the dialog and channel content for an existing draft before retrying.
3. Enter the title and description in the requested language. Replace the filename-based title, then verify the resulting text. Answer required audience and disclosure questions based on the video and the user's instructions.
4. Set the requested visibility and verify the selected option before saving. Use Unlisted (Registriväline) for link-only sharing. Resolve ambiguous visibility before saving.
5. Confirm the saved title and visibility in Studio and copy the video link from the share dialog or video details. Return the YouTube watch or share link. If processing or a restriction makes the video unavailable, check whether it clears and report any remaining blocker.
